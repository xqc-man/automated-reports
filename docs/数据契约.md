# 标准指标输入与快照契约 v1

## 接入边界

本版本只导入已经整理好的指标长表：每个案例、指标、期间一条记录。仅支持月度和自然季度；年度累计财务数必须由未来来源适配器转换后再输入。本版本不做自动换汇、跨来源拼接或原始订单去重。

输入为 UTF-8 CSV（允许 BOM）与 JSON 来源配置。默认样本见 `data/synthetic/`，固定测试材料见 `tests/fixtures/`。不以扩展名或下载地址推断数据真实性。

## CSV 字段

列名必须恰好包含下列字段，顺序不限；字符串两端空白会被去除。除 `value`、`currency`、`missing_reason` 外，输入字段不能为空。

| 字段 | 说明 |
| --- | --- |
| case_id | 案例标识，与来源配置一致 |
| metric_id | 支持的基础指标标识，见下表 |
| value | 有限数值；缺失时留空，不能写 NaN、Infinity 或文字 |
| unit | currency 或 count，按指标固定 |
| currency | 金额使用三个大写字母的币种标识，如 CNY；计数留空 |
| period_start | YYYY-MM-DD；完整月或自然季度首日 |
| period_end | 对应完整月或自然季度末日 |
| frequency | monthly 或 quarterly，与配置一致 |
| definition | 统计口径，同一指标跨期保持一致 |
| source_record_id | 对应来源配置 sources 的一个键 |
| status | original 或 missing |
| missing_reason | original 时为空；missing 时必填，value 必须为空 |

同一案例不混用币种；金额不使用“千元”等缩放单位。计数必须为非负整数；金额允许负数，是否符合业务含义由来源适配和口径说明确定。

### 基础指标

| metric_id | 单位 | 定义要求 |
| --- | --- | --- |
| sales_amount | currency | 样本销售额，不未经确认称为财务营收；说明退款、税费与取消订单 |
| orders_count | count | 有效且去重的订单数，非商品行数 |
| active_customers | count | 指定期间内去重的客户数，非账户总数或期末用户数 |
| net_profit | currency | 已有口径定义的单期净利润，模拟样本明确为虚构 |

可以只输入这些指标中的一部分，程序只计算已有基础序列支持的派生指标。完全没有输入的指标序列不凭空生成。增加真实案例指标时先修改契约、指标实现与对应测试。

## 来源配置 JSON

```json
{
  "case_id": "synthetic-shop",
  "case_name": "模拟商店（虚构）",
  "data_type": "synthetic",
  "frequency": "monthly",
  "license": "本项目生成的模拟数据，可用于功能演示",
  "display_window": {"start": "2024-01-01", "end": "2024-12-31"},
  "sources": {
    "synthetic-generator": {
      "url": null,
      "evidence": "scripts/generate_synthetic.py；固定随机种子；全部为虚构数据"
    }
  }
}
```

`data_type` 取 synthetic、real、anonymized。模拟来源的 url 必须为 null；真实或匿名化来源必须有 HTTP(S) URL，evidence 说明来源文件、表或原文位置，license 记录实际许可。阶段一尚未验证任何真实来源；程序不会证明声明的真实性或替用户检查再分发许可。

展示窗口必须由完整月份或自然季度组成，配置固定，不随当前日期移动。数据可包含窗口外的基线；规范化会在最早输入/窗口开始到最晚输入/窗口结束之间，为已有指标的缺失期间生成空记录，原因是 `period_not_provided`，来源留空。

## 派生指标

| metric_id | 公式 | 单位 |
| --- | --- | --- |
| average_order_value | sales_amount / orders_count | currency/order |
| sales_period_growth | 本期销售额 / 上一期销售额 - 1 | ratio |
| sales_yoy | 本期销售额 / 上年同期销售额 - 1 | ratio |
| sales_change | 本期销售额 - 上一期销售额 | currency |
| profit_change | 本期净利润 - 上一期净利润 | currency |

上一期按实际日历月或季度定位，上年同期为月度前 12 期或季度前 4 期。计算先覆盖全部输入及基线，再由查询筛选展示窗口。

- 分母为零：`not_comparable / zero_denominator`，不生成无穷大或零增长。
- 增长率基期为负：`not_comparable / negative_baseline`，可查看绝对变化。
- 增长率本期为负：`not_comparable / negative_current_value`，可查看绝对变化。
- 输入已存在但缺失：`missing / input_missing`。
- 所需基线在数据范围之前：`missing / baseline_not_available`。
- 计算成功：`derived`，保留公式和输入记录。

公式计算使用浮点数；ratio 以小数存储。无法计算的派生值保持空白，原因写入 missing_reason。

## 快照结构

`metrics.csv` 在输入列基础上增加：

- `formula`：派生指标公式，原始记录为空。
- `inputs`：JSON 数组，包含实际找到的输入指标、期间、数值、来源记录 ID 和状态。范围之外不存在的基线不制造来源，结合公式及缺失原因追溯。
- `data_type`：与来源配置一致。
- `data_notice`：模拟记录统一为“模拟数据，仅用于功能演示”。

`metadata.json` 包含 schema_version、snapshot_version、content_sha256、code_version、imported_at、source_config、quality、output_rows。

指标表内容使用 SHA-256 校验；快照版本由指标 CSV、排序规范化后的来源配置和代码版本计算，导入时间不参与版本。重复运行相同内容不会改变快照或首次导入时间。CSV 改行序但规范化结果相同时，版本也保持一致。quality 是首次生成此快照时的输入、去重、补缺统计；每次命令运行的实际统计另记在运行日志。

## 发布与读取

先在相邻临时目录写完两份文件并校验，再替换输出目录。已有快照先移到临时备份，安装失败则恢复备份；本地单进程使用，不承诺跨进程读写期间始终可见。输出目录如果有其他文件，拒绝替换。

读取时检查结构、版本、内容哈希、记录键、状态与模拟标识。哈希用于发现意外损坏，不是数据来源的真实性认证。

DuckDB 只在内存加载已校验指标表，查询使用参数绑定。默认按 source_config.display_window 筛选，`--all-periods` 可查看基线；查询不重新定义指标公式。
